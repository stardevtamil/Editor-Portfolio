# Star Creation — Portfolio

A responsive, single-page portfolio built with plain HTML, CSS and JavaScript. It includes your supplied portrait photos, logo and T-shirt mockup, six playable video projects, scrolling software and gear carousels, and responsive circular hero portrait styling. Open `index.html` in a browser to preview it.

## Personalize before publishing

1. Replace the award shields with your award PNG files and edit the descriptions in `script.js`.
2. Put your résumé in this folder as `resume.pdf` so the download button works.
3. Update the browser title, wordmark, email, or Instagram link if your brand details change. The current site uses starcreationofficial@gmail.com and your Star Creation Instagram profile.
4. Check that you have permission to show any client, college, or other people's work before publishing.

All layout and visual styling are local. Google Fonts are loaded from Google Fonts when online; fallback fonts are provided.
